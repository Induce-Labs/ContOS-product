# Frontend i18n

## Purpose

Localize ContOS UI chrome with `react-i18next`. English catalog: `public/locales/en/common.json`.

## Overview

- Init in `src/i18n/` (loaded from `main.tsx`).
- Components use `useTranslation()` and `t('key.path')`.
- Non-React helpers (e.g. `avatarTypeLabel`) use `i18n.t(...)` from the default export.
- Scraped/agent content uses `useTranslatedTexts` (Agents translate API); on failure, English is shown.

## Keys used in this pass

| Area | Namespace |
|------|-----------|
| Onboarding welcome / project type / competitors chrome | `onboarding.*` |
| Auth callback | `auth.callback.*` |
| Dashboard / analytics | `dashboard.*`, `analytics.*` |
| Competitor progress / panels | `pipeline.*`, `competitors.*` |
| Agents chrome + output section titles | `agents.*` |
| Profiling review / edit chrome | `profiling.*` |
| Workspace type labels | `workspaceTypes.*` |

## Limitations

- Do not invent keys; leave strings missing from the catalog in English.
- Question text and scraped competitor content are not fully catalog-driven.
- `OverviewWorkspaceHeader` is presentational (titles passed from parents).
